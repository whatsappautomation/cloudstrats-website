# Cloudstrats Website

World-class interactive marketing site for Cloudstrats Technologies Pvt. Ltd.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Included (V1)

- Home with 3D animated logo, service hierarchy, products, practices
- Services (full main/sub hierarchy + AI infra + SOC)
- Products (Abha, Miraya, Narad + Nayan/Akshar/Swar)
- Industries & use cases
- About (stats, values, certifications, presence)
- Contact (offices, phones, email form)
